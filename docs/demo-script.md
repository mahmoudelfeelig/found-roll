Target length: **3:35**. Hard stop: **3:45**. The public video must remain under the event's four-minute limit.

Record the entire video—from the opening disclosure through the final passport—as one continuous, unedited screen capture. Keep window and tab changes visible, including the move from the app to Google Cloud Console and the architecture diagram. Do not pause, cut, splice, hide a retry, substitute fixture output, or edit a failed run into a successful one.

This remains a recording plan, not evidence that a video exists. Entrant/team eligibility and the research-informed story mode are confirmed. Publication remains blocked until a dedicated active Google Cloud Free Trial project has the required APIs/IAM/quota, the live Gemini/ADK and Google Cloud receipts exist for the frozen run set, the repository/tag has verified judge access, and a public YouTube/Vimeo URL whose duration is verified below four minutes is available.

## Recording gate

Do not record the final demo until the following are true for the same frozen commit and fixture version:

- `found-roll-app` and `found-roll-simulator` are deployed as separately addressable Cloud Run services.
- The app health response reports the live analyst, pinned model, Firestore repository, Cloud Tasks, and HTTP simulator modes—not fixture or inline modes.
- `scripts/prepare-canonical-run.ps1` has reset both services from an authenticated terminal or Cloud Shell. Its identifier-only receipt binds the reset case, workflow epoch, staff-only original, model-authorized preview, current active pair, and live-mode health; `inventory_legacy_health_compatibility` is `false`. The browser has no reset authority; **Refresh case** is not reset.
- The independent demo, staff, and supervisor values have been loaded into their matching in-memory fields without exposing them. The strict non-mutating all-three probe has succeeded, and its configured actor IDs are recorded as identifiers only.
- The browser is a clean session at the hosted project URL, with judge-appropriate access already verified.
- The Cloud Console tabs are pre-opened to the exact app revision, simulator revision, Firestore passport, Cloud Task/queue, and correlated trace/log view for this project.
- The narration describes documented operational friction and never implies that a team member personally experienced the synthetic route.
- All screens, simulator responses, and narration say `SIMULATED` whenever Relay Post or the fictional custodians are shown.
- A log scan from the rehearsal contains no private answer, raw token, signed URL, model prompt/response, or claimant text.

## Presenter language guardrails

Say:

- “accepted claim evidence,” not “ownership verified”;
- “staff identity attestation,” not “identity was proven by AI”;
- “simulated relay service attestation,” not “courier confirmed possession”;
- “application-enforced, hash-linked event manifest,” not “immutable ledger”;
- “live model and Google Cloud services in this recorded run,” only after the console receipts are visible;
- “measured on 15 synthetic fixtures,” only if the final evaluation report contains that exact completed result.
- “descriptive local candidate top-three proxy 2/2 and question-bearing usefulness proxy 3/3,” only with “insufficient sample, thresholds incomplete, zero Gemini and zero Google Cloud calls” in the same statement.

Never say:

- that Grand Hall, Metro Loop, Northport Air, or Relay Post is a real integration;
- that a QR code or token proves a person physically possessed an item;
- that the system is human-free;
- that the system is production-ready, compliant, or accurate in the real world;
- that a local fixture response is a live Gemini, ADK, Cloud Tasks, or remote simulator result.
